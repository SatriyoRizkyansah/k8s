1. Cek Status Node:

   kubectl get nodes

   Hasil sukses: Akan muncul node bernama minikube dengan status Ready.

2. Cek Sistem Pods Bawaan K8s:

   kubectl get pods -A

   Hasil sukses: Kamu akan melihat daftar service internal K8s (seperti coredns, kube-apiserver, dll) dalam status Running.

3. Cek Status Minikube:

   minikube status

   Hasil sukses: host, kubelet, apiserver semuanya berstatus Running.

4. Buka Tampilan Dashboard (Opsional)
   Jika ingin melihat tampilan visual grafis (GUI) dari cluster yang baru saja dibuat, ketik perintah berikut:

   minikube dashboard

   Minikube akan otomatis membuka browser dan menampilkan dashboard Kubernetes lokal kamu.
